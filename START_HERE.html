SELF-HOSTED · WINDOWS OR LINUX

Run your truck-scale prototype.

No cloud account, subscription, or database server needed — everything runs on your own machine.

Use fictional data only. Everyone signed in shares the workflow data. An administrator can reset it from Settings, which affects every signed-in user.

Windows: three simple steps

  1. Extract the ZIP.Keep the complete folder together.
  2. Install Node.js 22 LTS.Download it from nodejs.org if needed.
  3. Double-click RUN_ON_WINDOWS.bat.It installs, builds, starts the server, and opens the app in your browser.

Linux

Run docker compose up -d --build in the extracted folder. See README.md for a plain Node.js + systemd alternative if you'd rather not use Docker.

Signing in

The app seeds a global administrator account plus a supervisor and operator per plant. See lib/auth-server.ts's seedUsers() for the exact accounts and passwords, or open README.md. Sign in as the administrator, then use Settings > Manage users to create real accounts.
